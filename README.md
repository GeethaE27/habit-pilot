# HabitPilot
 
Turn Screen Time Into Growth Time
 
HabitPilot is an AI-powered digital wellness application that helps users reduce social media addiction by replacing distractions with productive and healthy interventions.
 
## Features
 
- Social media usage tracking
- Wellness score
- Focus mode
- Breathing exercises
- Walking challenges
- AI-powered insights
- Habit streaks
 
## Tech Stack
 
- Flutter
- FastAPI
- Python
- SQLite
- AI/ML
